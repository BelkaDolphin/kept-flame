### 0.2 設計契約(この仕様が保証すること)

1. **記号は最優先チャネル**。マーカーが表示される限り記号は必ず描かれる。落とす順序は 数値 → パターン → (記号は最後まで残す)。
2. **4重符号化の完全形はタグチップ(44px角)で常に保証される**。格子セル内のマーカーは縮小時に劣化しうるが、セルタップ → 内訳ビュー(必ず44pxチップで描画)で完全形に到達できる。ADR-003(1)の「色単独表示の禁止」は全 LOD 段階で満たす(色が残る段階では記号も必ず残る)。
3. **面の色差だけで状態を伝えない**。セル面同士のコントラストは 1.06〜1.10:1 しかなく WCAG 1.4.11 を満たせないため、状態差は必ず**枠線またはハッチ**で冗長化する(§2.4)。
4. **パターンは ink 100% 不透明で描き、密度で濃淡を作る**。半透明(opacity/alpha)でパターンを薄めることを**禁止**する。合成後の実効輝度が上がりコントラスト計算値と実測値が乖離するため。

### 1.1 色の意味づけと選定理由

- **熱源 #8C290B(錆赤)** — 熾火・鍛冶。彩度の高い純赤(#FF0000系)は Y=0.21 で 4.5:1 を満たせないため、暗い赤橙を採る。
- **清浄 #076F5A(深緑青)** — 清水・衛生。当初案の水色(H=186)は3型で湿潤と ΔE00 5.9 まで接近したため H=168 へ寄せて 8.6 に改善(§3.3)。
- **汚染 #35240F(泥褐)** — 汚泥。パレット中**最暗**(Y=0.021)。低彩度＋最暗で「重い」意味論と弁別性を両立。
- **騒音 #671B75(深紫)** — 派手さ。暖色群/寒色群のどちらにも属さない中間色相で、1型/2型でも独立位置を保つ。
- **湿潤 #1942E5(青)** — 水。彩度は高いが、3型での 清浄 との分離に効くため意図的に高彩度を維持(§3.3 トレードオフ)。
- **静穏 #2D333E(暗スレート)** — 静けさ。**唯一の低彩度色**。彩度そのものが弁別チャネルとして機能し、色覚型を問わず「無彩色寄り」として認識されるため、7色中で最も CVD 耐性が高い。
- **学芸 #975D0C(黄土)** — 羊皮紙・書物。パレット中**最明**(Y=0.144)。汚染(最暗)と対になる暖色ペアで、明度差 2.76:1 を確保。

|---|---|
| cell 対 page | 1.06:1 |
| rubble 対 cell | 1.10:1 |
| cell-selected 対 cell | 1.08:1 |

したがって以下を必須とする。

- **瓦礫セル**: 面色だけでなく `--kf-line-rubble` の45°ハッチ(線幅1.5px・ピッチ6px)を重畳。ハッチ 対 瓦礫面 = **3.70:1**。
- **選択セル**: 面色だけでなく `--kf-ink-body` の2px枠線。枠線 対 選択面 = **14.17:1**。
- **配置プレビュー**: 面色だけでなく `+` / `−` バッジ + 数値ラベル(GDD §6.5)を必ず併記。

## 3. コントラスト計算(WCAG 2.x)

### 3.1 計算式と手順

各チャネル `C ∈ {R,G,B}` について `Cs = C8bit / 255`、

```
Clin = Cs / 12.92                       (Cs <= 0.03928)
Clin = ((Cs + 0.055) / 1.055) ^ 2.4     (Cs >  0.03928)
```

相対輝度 `Y = 0.2126·Rlin + 0.7152·Glin + 0.0722·Blin`
コントラスト比 `CR = (Ymax + 0.05) / (Ymin + 0.05)`

**計算例: `lore #975D0C` 対 `--kf-surface-page #FFFFFF`**

```
R = 0x97 = 151 -> Cs = 0.592157 -> Rlin = ((0.592157+0.055)/1.055)^2.4 = 0.309469
G = 0x5D =  93 -> Cs = 0.364706 -> Glin = ((0.364706+0.055)/1.055)^2.4 = 0.109462
B = 0x0C =  12 -> Cs = 0.047059 -> Blin = ((0.047059+0.055)/1.055)^2.4 = 0.003677
Y = 0.2126*0.309469 + 0.7152*0.109462 + 0.0722*0.003677
  = 0.065793 + 0.078287 + 0.000265 = 0.144346
CR = (1.0 + 0.05) / (0.144346 + 0.05) = 1.05 / 0.194346 = 5.4027 -> 5.40:1
```

**導出した設計上限**: `--kf-surface-rubble` (Y=0.8486) 上で text 4.5:1 を満たすには
`Yink <= (0.8486 + 0.05) / 4.5 - 0.05 = 0.14970`。
よってタグ ink の相対輝度上限は **Y ≤ 0.1497**。`lore` の Y=0.14435 はこの上限に対し余裕 3.6%。**この上限を超える色は採用していない**(この制約が palette 全体の明度レンジを Y∈[0.020, 0.150] に閉じ込めており、§4 の色覚設計が輝度差だけに頼れない根本理由でもある)。

## 4. 色覚多様性(P型/D型/T型)の検討

### 4.1 手法

1. **混同色線**: CIE1931 xy 色度図上で、各色が各型の共点(copunctal point)から見てどの方位角にあるかを算出。同一方位角(=同一混同色線上)の2色はその型で色相として区別不能になる。共点は P(0.7465, 0.2535) / D(1.4000, −0.4000) / T(0.1748, 0.0000)。
2. **二色覚シミュレーション**: Viénot・Brettel・Mollon (1999) の LMS 空間線形変換で P/D/T をシミュレートし、CIEDE2000 距離を算出。
   (実装検証: ΔE00 の参照値テスト Lab(50, 2.6772, −79.7751) 対 Lab(50, 0, −82.7485) = **2.0425** に一致することを確認済み。)

### 4.5 冗長化の根拠(色チャネルを完全に失っても弁別できること)

色を完全に除去した場合(グレースケール/モノクロ印刷/重度色覚異常)に残る2チャネルの対応表:

| id | 輪郭クラス(記号) | 塗りパターン |
|---|---|---|
| `heat` | 上向き三角(頂点上・底辺水平) | ベタ塗り 100% |
| `clean` | 二重同心円(中空) | 無地 0% |
| `foul` | 下向き三角(底辺上・頂点下) | 高密度ドット ≈53% |
| `noise` | 右に開く同心弧3本+中心点(非閉曲線) | 塗り無し 0%・多重線 |
| `damp` | 水滴(上尖り・下半円) | 横波線 ≈31% |
| `calm` | 横長スタジアム(角丸・幅広) | 縦ストライプ ≈25% |
| `lore` | 菱形(頂点4つが上下左右) | 45°クロスハッチ ≈41% |

- **輪郭は7種すべて位相/アスペクト比が異なる**。閉曲線(5種) vs 非閉曲線(noise)、直線多角形(heat/foul/lore) vs 曲線(clean/damp/calm)、縦長(heat/foul/damp) vs 等方(clean/lore) vs 横長(calm)。
- **パターンは密度と方向の2軸で分散**。密度 0% / 25% / 31% / 41% / 53% / 100%、方向 なし / 横 / 縦 / 45°両方向 / 点。
  - 密度が比較的近い `calm`(25%) と `damp`(31%) は**方向が直交**(縦直線 vs 横波)しており、密度差ではなく方向差で弁別する。
  - `clean`(無地) と `noise`(塗り無し) は同じ「塗り0%」だが、記号自体が閉曲線 vs 非閉曲線で決定的に異なる。
- P/D型で最も収束する暖色群 {heat, foul, lore} は **▲ / ▼ / ◆** と輪郭が最も遠い3種に割り当ててある(上向き / 下向き / 菱形)。これは偶然ではなく、混同色線解析の結果を受けた意図的な割当てである。
- P/D型で収束する寒色群 {noise, damp} は **⟩⟩⟩(非閉曲線) / ◗(閉曲線)** で、閉/非閉の位相差で弁別する。

### 4.6 残る限界(明記)

- **3型(T型)の clean/damp は ΔE00 8.6** で、全21ペア中2番目に近い(最小は heat/lore の 8.2)。T型の有病率は極めて低い(<0.01%)ため P/D型の分離を優先した設計判断である。記号(◎ 対 ◗)とパターン(無地 対 横波)で冗長化されているが、**色だけでの弁別は期待しない**。
- `damp #1942E5` は他6色より彩度が高く、アースカラー主体のパレットの中でやや浮く。これは T型での clean との分離(彩度を落とすと ΔE00 が 8.6 → 5.9 に悪化することを計測済み)を優先したトレードオフである。**視覚的統一を優先して彩度を落とす場合、T型の clean/damp 分離が ΔE00 5.9 まで低下することを承知の上で行うこと。**
- 本仕様は二色覚(dichromacy)でのシミュレーションであり、より一般的な**異常三色覚(anomalous trichromacy)は検証していない**。異常三色覚は二色覚より弁別能が高いため、二色覚で成立すれば包含されるという前提に立っている(この前提自体は本仕様では検証していない)。

## 5. 記号の作図仕様

### 5.1 共通規約

- 全記号は `viewBox="0 0 24 24"` の共通ユーザ空間で定義する。以降「u」= このユーザ空間の1単位。
- 描画サイズ `S`(CSS px)に対するスケール係数 `k = S / 24` [px/u]。
- コア領域は `x, y ∈ [2.2, 21.8]`。ストローク太りを含めてこの範囲に収める。
- `stroke-linejoin="round"` / `stroke-linecap="round"` を全記号に適用(小サイズで角が欠けるのを防ぐ)。
- 色は `currentColor` を使い、親要素の `color: var(--kf-tag-<id>-ink)` で決める。1記号=1色。
- **`full` と `mini` の2バリアント**を持つ。`full` は内部パターンを持ち、`mini` は輪郭のみのソリッド/太線。
- SVG スプライトは文書ルートに1個の隠し `<svg>`(`width=0 height=0 aria-hidden="true"`)として置き、`<use href="#kf-tag-heat-full">` で参照する。外部ファイル参照はしない(`<pattern>` 参照が同一文書内で解決される必要があるため)。

| `full` 輪郭ストローク | 2.5 | 4.58 | 2.92 | 2.08 | 1.46 | 1.25 | 1.04 |
| `mini` 輪郭ストローク | 4.0 | 7.33 | 4.67 | 3.33 | 2.33 | 2.00 | 1.67 |

(単位: CSS px)

**判読下限として採用する規則:**

| チャネル | 要求線幅 | 満たす最小 S | 扱い |
|---|---|---|---|
| `full` 輪郭ストローク (2.5u) | ≥1.5px **厳守** | **14.4px** | 割ったら `mini` へ切替 |
| `mini` 輪郭ストローク (4.0u) | ≥1.5px **厳守** | **9.0px** | 割ったらマーカーごと撤去 |

パターン線だけは 1.5px を厳守しない。**S=20〜27px の範囲(実線幅 1.08〜1.46px)は「暫定許容」とし、判読可否を #9b の実機計測で確定する**。S<20px では 1.08px を割るため無効化する(§7.2 L3)。輪郭ストロークと違い、パターンが潰れても種別の誤認には直結せず(記号輪郭が残る)、冗長チャネルの1本が欠けるだけであるため、この非対称な扱いを採る。

上記はいずれも **CSS px 基準**。devicePixelRatio による物理画素の増加は判読性の余裕として扱い、**要件の緩和には使わない**(ターゲット実機に低DPI機が含まれうるため)。

### 5.4 パターン定義

すべて `patternUnits="userSpaceOnUse"`(=24u 空間と同一スケール。記号を縮小するとパターンも比例縮小する)。**線・点は ink 100% 不透明**。地は tint。

| id | 定義 | 面積被覆率 |
|---|---|---|
| `kf-pat-foul` | tile 3.6×3.6。`<circle cx="0.9" cy="0.9" r="1.05"/>` + `<circle cx="2.7" cy="2.7" r="1.05"/>`(千鳥) | 53.5% |
| `kf-pat-damp` | tile 6×5.5。`<path d="M0 2.75 q1.5 -1.9 3 0 t3 0" stroke-width="1.6" fill="none"/>`(横波) | ≈31% |
| `kf-pat-calm` | tile 6.5×6.5。`<path d="M3.25 0 V6.5" stroke-width="1.6"/>`(縦線) | 24.6% |
| `kf-pat-lore` | tile 8×8。`<path d="M0 8 L8 0 M-1 1 L1 -1 M7 9 L9 7 M0 0 L8 8 M-1 7 L1 9 M7 -1 L9 1" stroke-width="1.3"/>`(45°/135°の2方向・角の断片はタイル継ぎ目用) | 40.7% |
| heat | パターン不使用(`fill` に ink をベタ指定) | 100% |
| clean / noise | パターン不使用(`fill="none"`) | 0% |

被覆率の算出: `foul` = 2·π·1.05² / 3.6² = 53.5%。`calm` = 6.5·1.6 / 6.5² = 24.6%。`lore` は45°線の垂直間隔が 8/√2 = 5.657u、1方向あたり duty = 1.3/5.657 = 23.0%、交差で 1−(1−0.230)² = 40.7%。`damp` は曲線長を直線長の約1.08倍として 6·1.08·1.6 / (6·5.5) ≈ 31%(**近似値**)。

`damp` の波は tile 内で y=1.80〜3.70 に収まり(ストローク込みで 1.00〜4.50)、tile 高 5.5 に対し上下 1.0u の余白を持つため、垂直方向にタイルしても波同士が接触しない。

パターンの背後には必ず tint のベタ塗りを敷く(`<path ... fill="TINT"/>` を先に描いてからパターンを重ねる)。これにより記号内部の地色が page/cell によらず一定になり、§3.2 の ink/tint コントラスト(≥4.62:1)が成立する。

## 7. ピンチ縮小時の劣化戦略(#9b の計測対象)

### 7.1 マーカーサイズの決定式

```
markerPx = clamp( round(0.273 * cellPx), 9, 26 )
cellPx   = 44 * zoom
```

`0.273 = 12/44`。zoom=1.0 で markerPx=12、zoom=2.0 で 24、zoom=0.75 で 9。

### 7.2 LOD 段階表

| 段 | markerPx | zoom 目安 | 色 | 記号 | パターン | 数値 | 有効チャネル数 |
|---|---|---|---|---|---|---|---|
| **L0** | 26(チップ固定) | ズーム非依存 | ○ | full | ○ | ○ | **4** |
| **L1** | 24〜26 | ≥1.956 | ○ | full | ○ | ○ | **4** |
| **L2** | 20〜23 | 1.623〜1.955 | ○ | full | ○(暫定許容) | × | 3 |
| **L3** | 15〜19 | 1.207〜1.622 | ○ | full | ×(tint ベタ) | × | 2 |
| **L4** | 9〜14 | 0.708〜1.206 | ○ | mini | × | × | 2 |
| **L5** | <9 | <0.708 | ○(集約) | 集約ドット | × | × | 1(種別不能) |

**落とす順序: 数値(L2で消失) → パターン(L3で消失) → 記号は L4 まで保持 → L5 で個別マーカー自体を撤去。**
記号を「細くして残す」ことはしない。判読不能な記号は誤認を生むため、閾値を割ったら別バリアント(mini)に切り替えるか、マーカーごと撤去する。

各段の根拠:

- **L2 で数値を落とす**: 11px フォントを 24px 未満のマーカーに収めると字面が 6px 相当まで落ち、コントラスト 4.5:1 を満たしていても判読できない。
- **L3 でパターンを落とす**: パターン線 1.3u が 1.5px を割るのが S=27.7px。L2(20〜23px)ではチップ用オーバーライド(1.4u)を流用しても 1.17〜1.34px にしかならないため「暫定許容」区間とし、S<20px(1.08px 未満)で無効化する(§5.2)。
- **L4 で mini へ切替**: `full` の 2.5u ストロークが 1.5px を割るのが S=14.4px。`mini` の 4.0u なら S=9px まで 1.5px を維持する。
- **L5 で撤去**: S<9px では mini でもストロークが 1.5px を割る。個別マーカーを消し、セル中央下に `--kf-ink-body` の 5px ドットを1個だけ置いて「タグあり(種別は要タップ)」を示す。

zoom 境界は `markerPx = round(12.012 × zoom)` の丸め境界から導出(zoom=1.0 で markerPx=12)。zoom ≥ 2.123 で clamp 上限 26px に張り付く。

### 7.3 最小判読スケールの目標値(#9b の合否基準案)

| 指標 | 目標 |
|---|---|
| 7種の記号を**正しく種別まで同定**できる最小マーカーサイズ | **12 CSS px**(L4 上端付近) |
| 「タグが存在すること」を認識できる最小マーカーサイズ | **9 CSS px** |
| 上記を満たす最小ズーム倍率 | **zoom ≥ 1.0**(=セル44px・markerPx=12)で種別同定可、**zoom ≥ 0.708**(markerPx=9)で存在認識可 |
| 格子全体(6×8=48セル)を1画面に収めた時の zoom | 実機計測で確定。**これが 0.708 を下回る場合、格子ビューは L5 前提となり、種別同定はセルタップ経由に一本化する** |

L5 に落ちること自体は仕様違反ではない(ADR-003(1) の「色単独表示の禁止」は L5 では個別の色表示自体を行わないことで満たす)。ただし **L5 が既定のズームになる場合は UX 上の設計見直しが必要**であり、#9b の主要な確認事項とする。

### 7.4 非スケーリング要素(ズームに追従しないもの)

- 過密警告バッジ: 常に 12px 以上
- キーボードフォーカスリング: `--kf-ink-body` 3px、オフセット 2px、常に固定太さ(対 page 16.17:1)
- 選択セル枠線: 常に 2px 以上

## 9. 未確定点(ユーザー/後続タスクへの申し送り)

1. **格子全体を1画面に収めた時の実ズーム倍率が未知**。これが 0.708 を下回ると既定表示が L5(タグ種別が読めない)になる。#9b の実機計測で確定するまで、格子ビューの既定ズームは決められない(§7.3)。
2. **`damp` の彩度**は T型分離を優先して高めに置いてある。パレットの視覚的統一を優先して落とす場合、T型の clean/damp が ΔE00 8.6 → 5.9 に悪化する。**どちらを採るかはユーザー判断**(§4.6)。
3. **異常三色覚(anomalous trichromacy)は未検証**。二色覚で成立すれば包含されるという前提を置いているが、この前提自体を検証していない(§4.6)。
4. **チップ用パターン線幅のオーバーライド(1.3u → 1.4u)**は S=26px でパターン線を 1.5px に載せるための措置。実装後に他サイズとの見た目の一貫性を目視確認すること(§6.1)。
5. **過密警告バッジの記号**(`!` 内包三角)は heat の上向き三角と輪郭が近い。`--kf-line-grid` の 1px 縁取りで区別する設計だが、これは T13後半の bench で目視確認が必要(§6.4)。
6. **`--kf-line-grid #8A857D` は対 cell 3.46:1** と下限に近い。格子線をこれ以上明るくすると WCAG 1.4.11 を割る(§2.3)。
