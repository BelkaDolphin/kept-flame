## 1. bot用GitHubアカウント + PAT の作成(M45の前提・優先度: 中)

**目的**: ソロ運営のレビュー分離(ADR-030)。bot identity が週次 content PR を作成し、運営者本人(BelkaDolphin)が CODEOWNERS レビュアーとして承認する二役分離を成立させる。**自分のPRは自分で承認できない**というGitHubの仕様上、別アカウントが必須。

手順:

1. GitHub で machine user アカウントを新規作成(例: `belka-kept-flame-bot`)。GitHub利用規約上、1人1つまで machine user は許容されている
2. `kept-flame` リポジトリに bot アカウントを **Write 権限のコラボレータ**として招待し、bot側で承諾
3. bot アカウントで **fine-grained PAT** を作成:
   - Repository access: `kept-flame` のみ
   - Permissions: Contents = Read and write / Pull requests = Read and write
   - 有効期限は90日以内を推奨(失効したら作り直す運用)
4. PAT は**ローカルにのみ**保管(パスワードマネージャ等)。**GitHub Actions の secrets には登録しない**(M45の検収条件: PAT が `pull_request_target` へ渡らないこと・ADR-021)
5. 用意できたら Claude に「bot PAT 用意できた」と伝える → M45(push/PRスクリプト+ブランチ保護設定+承認merge実演)を実施する

**これが無いと進まないもの**: M45 のみ。他の全タスクは進行可能。
