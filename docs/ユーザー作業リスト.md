## 1. GitHub App `kept-flame-bot` の作成(M45の前提・優先度: 中)

**[2026-07-28改訂・ユーザー承認済み]** 旧「botアカウント+PAT」方式は廃止(fine-grained PAT が他人所有リポに発行できない公式既知ギャップ+アカウント作成困難のため)。**新規アカウント不要・メール不要・2FA不要**の GitHub App 方式に変更(ADR-030 [2026-07-28改訂]が正本)。

**目的**: ソロ運営のレビュー分離(ADR-030)。App が週次 content PR を作成し、運営者本人(BelkaDolphin)が CODEOWNERS レビュアーとして承認する二役分離を成立させる。

手順(所要5分・すべて BelkaDolphin アカウントのまま):

1. GitHub → Settings → **Developer settings → GitHub Apps → New GitHub App**
2. GitHub App name: `kept-flame-bot`(名前がグローバル重複したら適当なサフィックスを付ける)。Homepage URL はリポジトリ URL でよい
3. **Webhook の「Active」チェックを外す**(Webhook URL の入力が不要になる)
4. Repository permissions は **2つだけ**: **Contents = Read and write** / **Pull requests = Read and write**(Metadata read-only は自動付与)
5. 「Where can this app be installed?」= **Only on this account** → Create GitHub App
6. 作成直後の画面で **App ID を控える** → 下部の **Generate a private key** を押す(.pem がダウンロードされる)
7. 左メニュー **Install App** → BelkaDolphin → **Only select repositories** で `kept-flame` のみを選んでインストール
8. .pem は**リポジトリ外**に保管(パスワードマネージャ、または `C:\Users\dolph\` 配下の非リポジトリフォルダ)。**絶対にコミットしない・GitHub Actions の secrets にも登録しない**(ADR-021)
9. 用意できたら Claude に「App作った。App ID = XXX、.pem は <場所>」と伝える → M45(トークン発行+push/PRスクリプト+ブランチ保護設定+承認merge実演)を実施する

**これが無いと進まないもの**: M45 のみ。他の全タスクは進行可能。
